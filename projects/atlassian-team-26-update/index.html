Atlassian Cloud Platform

🛡️

Atlassian Guard

아틀라시안 가드는 엔터프라이즈 보안, 데이터 손실 방지(DLP), AI 데이터 거버넌스를 통합 제공하는 클라우드 보안 솔루션입니다.

🔐

Guard Standard

기본 보안 기능을 담당합니다:

  • SSO (Single Sign-On)
  • SCIM (자동화된 사용자 프로비저닝)
  • MFA (다단계 인증)
  • 모바일 정책
  • 관리자 감사 로그
🏆

Guard Premium

Standard 포함 + 고급 기능:

  • 고급 데이터 보호
  • 위협 감지
  • 사고 대응 (Jira, Confluence 등)
  • DLP (데이터 손실 방지)
  • Rovo Connector 데이터 보안
🔐 체계 확립

Standard 및 Premium 체계

Guard Standard는 SSO, SCIM, MFA, 모바일 정책 및 관리자 감사 로그 같은 기본 보안을 담당합니다. Guard Premium은 Jira, Confluence 등 지원 제품 전반에 걸친 고급 데이터 보호, 위협 감지 및 사고 대응 기능을 추가 제공합니다.

출처: 🔗 Atlassian Community
🔍 DLP EAP

데이터 가시성 및 대규모 분류

Guard Premium에서 제공하는 DLP(Data Loss Prevention) 기능:

  • 전체 사이트 스캔
  • 향상된 기본 감지 규칙
  • 자동 데이터 분류 및 재분류 제어
출처: 🔗 Feature Focus Vol.5
